# The reference data, and the order to match it in

Everything here is pinned in `golden/MANIFEST.json` by sha256 and byte count, enforced by
`tests/golden-fixtures.test.cjs`. Nothing in `golden/` is edited; it is regenerated by an
explicit decision (`docs/CORE-REPLAN.md`), because it is the contract of the *rules*, recorded
from the JavaScript reference and never from a port.

| file | what it is |
|---|---|
| `golden/stream-b1040-1m.jsonl` | a one-minute four-seat match, 2,722,912 bytes |
| `golden/map-line-b1040.json` | the map record out of it: seed `golden`, `medium`, 4 seats, **942** resource nodes in integer millimetres |
| `golden/turn1-b1040.jsonl` | one state per seat after the first tick |
| `samples/golden/initial/golden-initial.jsonl` | the opening snapshot |
| `golden/keyed-vectors.md` | the two draws below |

## The vectors, as exact integers

The reference's `draw()` returns a double in [0,1); the exact numerator is the fact worth
matching, because a decimal rendering invites a reader to trust a rounding.

| draw | u32 | as printed by JS |
|---|---|---|
| `keyed("golden")`, `draw("s0:start-workers")`, n=0 | `0xa9b8bccd` | `0.6629751205909997` |
| same key, n=1 | `0x9fd153da` | `0.6242878348566592` |

`spike/odin/main.odin` reproduces both. Regenerate the expectations with:

    node -e 'const R=require("./js/simulation/rng.js"),s=R.keyed("golden"),k="s0:start-workers";
             for (let i=0;i<2;i++){const v=R.draw(s,k);console.log(v,"0x"+Math.round(v*4294967296).toString(16));}'

## The gates, in the order they are worth attempting

1. **The two vectors.** A dozen lines of transcription. This is the cheapest possible proof that
   the discipline holds, and it is what `spike/gates.sh` gate 2 checks. Done (green).
2. **The map line** — 942 nodes, byte-identical. Costs the terrain tables (`data.rs`'s
   equivalent in the reference's constants) and the node-placement loop with its
   `Math.max(1, round(...))` edges. The map is pure functions of a seed, so it needs no rule
   brain and cannot be faked.
3. **Turn 1** — four states, which requires the rule brain, the economy, the worker spread, and
   the clock reading 1 and not 0 (the bug the porting gate caught in Rust, before review).
4. **A whole match** — the stream, which is where `sim/run.js`'s command queue and the late-answer
   rejection rule finally have to be more than a TODO.
